# The Cat's Exit Interview

One line, one meeting nobody asked for: the cat finally sits its human down for an exit interview, and it turns out the human was never the boss — just an employee who has now been fired, with a single hairball on the good rug as the entire severance.

## Run it

```sh
node main.ts
```

This writes the joke line to `/output/entry.txt`.
